
# Deepfake Basics

Deepfakes are synthetic or manipulated media produced or altered using machine
learning methods. Common categories include face swapping, facial reenactment,
expression manipulation, and fully synthetic faces.

A detector is a statistical classifier and should not be treated as absolute proof
of authenticity. Performance can change with the image source, compression,
camera pipeline, generation method, post-processing, and distribution shift.

Possible visual indicators discussed in deepfake detection include blending
inconsistencies, unusual facial texture, boundary artifacts, and local detail
inconsistencies. These cues are not universal and may disappear after compression
or improved synthesis.
